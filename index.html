Le, la, un, une : choisis le bon article.

0 / 0Mode : tous les mots

Masculin (un / le)

Mots en -age : le fromage, le voyage (mais : la page, la plage, l'image)
Mots en -ment : le moment, le logement
Mots en -eau : le bureau, le gâteau (mais : l'eau = féminin)
Mots en -isme : le racisme, le tourisme
Jours, mois, saisons : le lundi, le printemps

Féminin (une / la)

Mots en -tion / -sion : la question, la télévision
Mots en -té : la liberté, la santé (mais : l'été = masculin)
Mots en -ure : la voiture, la culture
Mots en -ette : la baguette, la fourchette
Mots en -ie : la boulangerie, la vie

L'

Avant une voyelle : l' pour les deux. L'ami (m), l'école (f). Pour savoir, pense à « un ami », « une école ».

Pièges avec l'allemand

der Tisch → la table · die Sonne → le soleil · das Mädchen → la fille · der Mond → la lune
